Monta o site www.salekim.com.br do começo ao fim.

== Descrição ==

Ao ativar, o plugin:

* cria as páginas Início, Sobre, Para empresas, Programas, Clientes, Contato, Conteúdos e Política de privacidade, com os textos do briefing;
* cadastra os 6 programas para pessoas e os 4 serviços para empresas;
* cria o menu, define a página inicial e ativa os endereços amigáveis;
* manda para a lixeira o conteúdo de demonstração (Olá, mundo!, Página de exemplo, textos Lorem ipsum);
* desenha o layout (cabeçalho, rodapé, cores e fontes da marca) por cima de qualquer tema.

Inclui os formulários "Pedir proposta" e "Quero saber mais / lista de espera" (com envio para genira@salekim.com.br e cópia guardada no painel), botão flutuante de WhatsApp, aviso de cookies (LGPD), Google Analytics 4 e Meta Pixel carregados só com consentimento, SEO básico e dados estruturados para o Google.

Nada é apagado: páginas antigas com o mesmo endereço ganham uma revisão antes do texto novo, e a demonstração vai para a lixeira.

== Instalação ==

1. Painel do WordPress > Plugins > Adicionar novo > Enviar plugin.
2. Escolha salekim-site.zip e clique em Instalar agora. Se já existir uma versão anterior, escolha "Substituir a atual pela enviada".
3. Clique em Ativar.
4. Abra SALEKIM > Montar o site e siga a lista "O que falta".

Guia completo em LEIA-ME.md.
